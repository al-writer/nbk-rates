# nbk-rates

Архив **официальных курсов Национального банка Республики Казахстан**. Данные собираются
автоматически из [официального RSS НБ РК](https://nationalbank.kz/rss/get_rates.cfm) и
публикуются как статические JSON-файлы через GitHub Pages — их удобно читать прямо из браузера
(Pages отдаёт `Access-Control-Allow-Origin: *`).

## Адреса
| Что | URL |
|---|---|
| Актуальные курсы | `https://al-writer.github.io/nbk-rates/latest.json` |
| Курсы на дату | `https://al-writer.github.io/nbk-rates/ГГГГ/ММ/ДД-ММ-ГГГГ.json` |

Пример: курсы за 4 ноября 2026 — `2026/11/04-11-2026.json`. Курсы есть на **каждый календарный день**
(в выходные и праздники Нацбанк сохраняет последнее значение). Файл за дату, которой ещё нет, вернёт 404.

## Формат файла
```json
{
  "date": "2026-11-04",
  "source": "https://nationalbank.kz/rss/get_rates.cfm?fdate=04.11.2026",
  "fetchedAt": "2026-11-04T08:40:31.894Z",
  "rates": { "USD": 453.26, "EUR": 506.7, "RUB": 5.58, "KRW": 0.3371 }
}
```
`rates` — **тенге за одну единицу** валюты. В исходном XML часть валют публикуется за пачку
(`quant`: KRW — за 100, VND — за 1000 и т.д.); скрипт уже делит значение на `quant`, значения округлены до 8 знаков.

## Как работает
Workflow [`rates.yml`](.github/workflows/rates.yml) запускается два раза в сутки (08:17 и 20:47 по Алматы),
при ручном запуске и при изменении скриптов:

1. скачивает курсы за сегодня (по Алматы) и догоняет пропущенные дни за последние 7;
2. записывает новые файлы, коммитит их в `main` (прошедшие дни не перезаписываются; значение за сегодня
   обновляется, только если Нацбанк его изменил);
3. публикует репозиторий на GitHub Pages.

### Бэкфилл истории
Actions → **Update rates** → *Run workflow* → поле `from`, например `2020-01-01`.
Нацбанк отдаёт курсы и за прошлые годы; скрипт делает паузы между запросами.

### Локально
```bash
npm test
node scripts/fetch-rates.mjs                  # сегодня + догонка
FROM=2024-01-01 node scripts/fetch-rates.mjs  # бэкфилл
```
Нужен Node.js 20+, зависимостей нет.

## Настройка (один раз)
Settings → Pages → Build and deployment → Source: **GitHub Actions**.

## Замечания
- GitHub отключает расписания в публичных репозиториях после 60 дней без активности; новые данные
  коммитятся почти ежедневно, но при длительной паузе запустите workflow вручную.
- Данные принадлежат Национальному банку РК; репозиторий лишь хранит их копию. Для юридически значимых
  расчётов используйте официальный источник.
